# Jobcraft - Send job (Chrome extension)

Sends the job you are looking at to your Jobcraft **Add job** page, filled in. You check it and click **Analyse job** yourself.

- Works best on **LinkedIn** and **Naukri** job pages; other careers pages use a best guess.
- Tip: highlight the description on any page before clicking - the highlighted text is always used.
- Reads a page only when you click the extension, and only that tab. Sends nothing anywhere except your own Jobcraft tab.

## Install (Developer mode)
1. Open `chrome://extensions` in Chrome.
2. Turn on **Developer mode** (top right).
3. Click **Load unpacked** and choose this `extension` folder.
4. Pin it: click the puzzle icon in the toolbar, then the pin next to **Jobcraft - Send job**.

Stay logged in to Jobcraft in the same Chrome profile.
